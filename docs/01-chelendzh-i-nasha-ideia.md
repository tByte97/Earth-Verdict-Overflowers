# 01 · Челендж і наша ідея

Джерела: сторінка челенджу (вкладки Details і Resources, зчитано 14.11.2026) і попередня сесія
Claude Code від 27.10–02.11.2026, де ми обирали тему й робили прототипи.

## Що вимагає челендж

**Be An Earth System Trend Detective!** · складність Advanced · теми Earth Science, Software.

Завдання одним реченням: зробити інструмент, який обирає змінні з місій або моделей наук про
Землю, показує їх зміну в часі та визначає, **що** змінюється, **де**, **наскільки** і чи є
зміна **значущою**.

Чотири обов'язкові елементи (розділ Objectives):

| № | Елемент | Що це означає для продукту |
|---|---|---|
| 1 | Обрати змінну | Каталог змінних, від простих (температура, опади) до складних (випаровування, стік) |
| 2 | Отримати дані для регіону | Більшість трендів не глобальні, тож потрібен вибір місця |
| 3 | Побудувати часовий ряд | Ряд має бути достатньо довгим для статистики |
| 4 | Порахувати швидкість зміни і значущість | Методи названо прямо: t-test, Манна–Кендалла, довірчі інтервали |

Ключова фраза оцінювання: *«A response that does both the visualization and the analysis meets
the full scope of this challenge»*. Тобто сайти даних уміють будувати ряди, статистичні пакети
вміють рахувати значущість, а від нас чекають обидва кроки в одному інструменті.

Необов'язкові побажання (Potential Considerations):

- **Аудиторія**: старшокласники, студенти, люди з базовою науковою підготовкою. Прості
  визначення змінних «значно допоможуть».
- **Роль користувача**: «data detective».
- **Вхід через запитання**: коротка серія питань «що або де дослідити», за відповідями
  підбираються змінні.
- **Демо-приклади**, які користувач може *подивитися*, щоб зрозуміти інструмент.
- **SI (так NASA цього року називає ШІ)**: підбирати дані з потенційним трендом за новинами,
  науковими статтями або за типом регіону. Типи названо: пустеля, дощовий ліс, приливний
  естуарій, атмосфера над великим містом.
- **Дані**: найзручніші добові й місячні.
- **Незначущий тренд теж цікавий**: «інколи тренду для значущості бракує лише довшого ряду».
- **CUAHSI** згадано як зовнішнє джерело інструментів для гідрології.
- **Складність**: нелінійні тренди й зняття сезонності виходять за межі очікуваного. Лінійні
  тренди названо «чудовим початком».

Місії й моделі, названі в тексті: **MODIS, OMI, AIRS, GPM** (прилади), **MERRA-2, GLDAS**
(моделі).

Гачок із першого абзацу, який варто обіграти: одна змінна може рости в одному регіоні й падати
в іншому, *хоча причина та сама*.

## Наша ідея (зі сесії 02.11.2026)

Формулювання Максима: *«глобус зліва, а справа учень щось вводить, LLM обробляє, і тоді на
глобусі відбувається візуалізація»*. Після цього: *«ось на цьому і зупинемось»*.

Як ми це розписали:

1. Учень пише твердження або питання звичайною мовою: «Чи стало спекотніше влітку в Одесі?».
2. LLM викликає інструменти: геокодування, підбір змінної й сезону, отримання ряду, тест тренду.
3. Глобус летить у регіон і фарбує клітинки за швидкістю тренду. Значущі клітинки яскраві,
   незначущі бліді.
4. Праворуч з'являється картка-вердикт: **Підтверджено / Не доведено / Спростовано**, графік,
   швидкість зміни за десятиліття, пояснення під вік.

Головне правило: **модель не пише жодного числа, якого не повернув інструмент**. Тренд і
значущість рахує код, LLM лише ставить питання й пояснює відповідь.

Hero-фіча: «Перевір твердження». Друга сильна ідея з прототипу: «Time of Emergence», тобто рік,
починаючи з якого тренд стабільно значущий.

## Що вже є з розвідки

Прототип `~/Documents/varve-trend-detective` (30.10.2026). За правилами Space Apps це
розвідка: на хакатоні код пишеться заново в новому репозиторії.

| Що | Стан у прототипі |
|---|---|
| Глобус | MapLibre, перехід глобус → 2D-мапа, переліт між регіонами |
| Дані | NASA POWER (MERRA-2 і CERES), сітка 34–64°N, 12°W–48°E, 1981–2025 |
| Змінні | 5: температура, опади, волога ґрунту, глибина снігу, сонячне світло |
| Статистика | Нахил Сена і тест Манна–Кендалла з поправкою на автокореляцію, 95% інтервал, усе в браузері |
| Справи | 6 готових, підтверджених даними; одна навмисно закінчується «не доведено» |
| Питання текстом | Є, але на ключових словах, без LLM |
| Протилежні тренди | Є як «Leads» |
| Будь-яка точка Землі | Є, через POWER point API |

Відомі слабкі місця прототипу: лише 5 змінних і всі з однієї моделі; POWER округлює вологу
ґрунту до 0.01; немає поправки на множинні порівняння; жодної з названих у челенджі
супутникових місій (MODIS, OMI, AIRS, GPM) у даних немає.

Саме останній пункт ресурси з 13.11 дозволяють закрити. Деталі в `03` і `05`.
