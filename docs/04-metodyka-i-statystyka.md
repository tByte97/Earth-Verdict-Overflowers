## Що називає челендж

Три методи: **t-test**, **тест Манна–Кендалла**, **довірчі інтервали**. Лінійного тренду
достатньо. Зняття сезонності згадано як ускладнення, яке «інколи потрібне, щоб тренд
проявився».

## Методи

### Лінійна регресія з t-тестом

Це метод зі статті NASA (там його подано як F-тест; для однієї змінної це те саме, F = t²).

```
нахил    b = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²
залишки  s² = Σ(y − (a + b·x))² / (n − 2)
похибка  SE(b) = s / √Σ(x−x̄)²
статистика t = b / SE(b),  ступенів свободи n − 2
```

- Припущення: залишки незалежні, з однаковим розкидом, приблизно нормальні.
- Коли підводить: викиди тягнуть лінію на себе; залежність сусідніх значень занижує похибку й
  створює хибну значущість.
- Для учня: «проводимо пряму, найближчу до всіх точок одразу, і питаємо, чи міг такий нахил
  вийти випадково».

### Тест Манна–Кендалла

```
S = Σ sgn(x_j − x_i) для всіх пар i < j
Var(S) = [n(n−1)(2n+5) − Σ t(t−1)(2t+5)] / 18      (t: розміри груп однакових значень)
Z = (S − 1)/√Var(S), якщо S > 0;  (S + 1)/√Var(S), якщо S < 0;  0, якщо S = 0
```

- Припущення: тренд монотонний, значення незалежні. Нормальності й лінійності не потрібно.
- Коли підводить: залежність сусідніх значень, незнята сезонність, різкий стрибок у даних.
- Для учня: «для кожної пари років дивимося, пізніший вищий чи нижчий, і рахуємо, яких пар
  більше».

### Нахил Сена

```
для всіх пар i < j:  k_ij = (x_j − x_i) / (j − i)
нахил = медіана всіх k_ij
95% інтервал: межі беруться з відсортованого списку k_ij за рангами
  M1 = (N − C)/2,  M2 = (N + C)/2 + 1,  де N = n(n−1)/2,  C = 1.96·√Var(S)
```

- Витримує до ~29% довільних викидів.
- Для учня: «рахуємо нахил між кожною парою точок і беремо середній за порядком, тож кілька
  диких значень нічого не вирішують».

### Сезонний тест Манна–Кендалла

Січні порівнюються лише із січнями, липні з липнями; статистики за місяцями додаються. Підводить,
коли сезони мають протилежні тренди: вони взаємно гасяться.

### Блоковий бутстреп

Ряд ріжеться на суміжні шматки, шматки тисячу разів перемішуються, тренд перераховується.
Розкид результатів дає довірчий інтервал. Для рядів коротших за 25 точок ненадійний: замало
незалежних шматків.

## Автокореляція: головна пастка

Кліматичні величини мають «пам'ять»: теплий рік частіше йде за теплим. Формули вище
припускають, що кожна точка є незалежним свідченням. Якщо це не так, справжньої інформації
менше, ніж точок, і тест видає p < 0.01 для випадкового блукання.

Поправки:

| Спосіб | Суть | Джерело |
|---|---|---|
| Ефективний розмір вибірки | `n_eff = n·(1 − r1)/(1 + r1)`, де r1 є кореляцією сусідніх залишків; підставляється в t-test | Santer та ін., 2000 |
| Множник дисперсії для Манна–Кендалла | `Var(S)` множиться на `(1 + r1)/(1 − r1)` | те саме за змістом |
| Поправка Хамеда–Рао | Точніший множник за кореляціями рангів на всіх зсувах | Hamed, Rao, 1998 |
| Вибілювання без тренду (TFPW) | Зняти тренд → оцінити r1 → прибрати залежність → повернути тренд → тест | Yue та ін., 2002 |
| Блоковий бутстреп | Перемішування шматками довжиною близько ∛n | — |

У прототипі вже стоїть другий рядок. Рекомендація Flash, з якою я згоден:

- **річні ряди 25–45 точок**: нахил Сена плюс поправка дисперсії (як у прототипі) або TFPW;
- **місячні аномалії 300–500 точок**: регресія з `n_eff` або блоковий бутстреп із блоком
  12–24 місяці.

## Сезонність: три способи

| Спосіб | Плюси | Мінуси |
|---|---|---|
| Одне значення на рік (середнє за сезон або рік) | Сезонний цикл зникає повністю; мінімум автокореляції; легко пояснити | Втрачається більшість точок; не видно різниці між сезонами, якщо брати рік |
| Місячні аномалії (місяць мінус його багаторічне середнє) | Усі точки на графіку; так роблять NASA і NOAA | Сусідні місяці залежні; результат залежить від базового періоду |
| Сезонний Манн–Кендалл | Суворий, без базового періоду | Важко пояснити школяреві; гасить протилежні сезонні тренди |

Стаття NASA використала другий спосіб, згорнутий до років. Прототип використовує перший (один
сезон на рік), і це вдалий вибір: він дозволяє ставити питання «чи стало спекотніше *влітку*».
Flash вважає найпростішим для пояснення другий спосіб. Обидва захищаються; змінювати прототип
не бачу причин.

## Скільки років потрібно, щоб побачити тренд

Формула Weatherhead та ін., 1998: кількість років, після якої тренд виявляється з імовірністю
90% на рівні 95%.

```
n* = [ (3.3 · σ / |ω|) · √((1 + φ)/(1 − φ)) ]^(2/3)

σ: розкид шуму після зняття тренду
ω: тренд за рік
φ: автокореляція сусідніх років
```

Приклад, перерахований мною: σ = 0.8 °C, φ = 0.2, тренд 0.4 °C за десятиліття (0.04 за рік).

```
0.8 / 0.04 = 20
√(1.2/0.8) = 1.225
3.3 · 20 · 1.225 = 80.8
80.8^(2/3) ≈ 18.7 року
```

Тобто близько 19 років. Ця формула є готовою основою для відповіді «скільки ще чекати», коли
вердикт «не доведено».

## «Час появи сигналу»

У літературі (Hawkins, Sutton, 2012) Time of Emergence означає рік, коли сигнал зміни стабільно
перевищує природну мінливість: відношення сигналу до шуму більше 1 або 2 відносно базового
періоду.

У прототипі під цією назвою зроблено інше: рік, починаючи з якого тест Манна–Кендалла
лишається значущим. Різниця:

- p-значення залежить від довжини ряду; дуже довгий ряд зробить значущою мізерну зміну;
- класичне визначення міряє відхилення від базового періоду, а не всередині довільного вікна;
- пошук «першого значущого року» заднім числом трохи упереджений.

Висновок: функцію лишити, але **не називати її Time of Emergence** перед журі з науковців.
Чесна назва: «рік, з якого тренд стабільно значущий» або «коли сигнал вийшов із шуму». Якщо
хочеться класичного визначення, воно рахується просто: `тренд · роки / σ > 1`.

## Карта: множинні порівняння

Якщо перевірити 2000 клітинок на рівні 0.05, близько 100 засвітяться випадково. Через
просторову зв'язаність клімату вони ще й збираються в плями, схожі на справжні регіони
(Wilks, 2016).

Процедура Беньяміні–Хохберга:

```
1. Відсортувати всі p за зростанням: p(1) ≤ p(2) ≤ … ≤ p(m)
2. Для кожного рангу i поріг: (i / m) · 0.05
3. Знайти найбільший ранг k, де p(k) ≤ поріг(k)
4. Значущими вважати лише клітинки з p ≤ p(k)
```

Десять рядків коду. У прототипі цього немає (є лише порівняння з очікуваними 5%). Додати
варто: це закриває найімовірніше запитання науковця з журі.

## Стрибок замість тренду

Заміна приладу, перенесення станції, зміна версії моделі дають різку сходинку. Тест сприймає
її за плавний тренд. Тест Петтіта (1979) знаходить рік найімовірнішого зламу:

```
U_t = 2·Σ(ранги перших t значень) − t·(T + 1)
рік зламу: де |U_t| найбільше
p ≈ 2·exp(−6·K² / (T³ + T²)),  K = max|U_t|
```

Де це стосується нас: стик GLDAS 2.0 і 2.1, станційні ряди NOAA, перехід між супутниками.
Мінімальний варіант без тесту: попередження в картці, коли джерело відоме своїми стиками.

## Вісім типових помилок

1. Плутати статистичну значущість із важливістю: p < 0.001 для 0.001 °C за століття.
2. Не враховувати автокореляцію на добових і місячних даних.
3. Підбирати початок і кінець ряду під бажаний результат (старт у рік сильного Ель-Ніньйо).
4. Проводити пряму крізь незнятий сезонний цикл.
5. Довіряти звичайній регресії там, де є викиди. Саме це показала стаття NASA на Міссісіпі.
6. Фарбувати на карті кожну клітинку з p < 0.05 без поправки.
7. Приймати стрибок від заміни приладу за тренд.
8. Вважати пропуски нулями або стискати ряд, ніби пропусків немає.
