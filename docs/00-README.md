## П'ять головних висновків

1. **Ніша продукту сформульована самим NASA.** Giovanni будує ряд і малює лінію регресії, але
   значущість не перевіряє і в посібнику застерігає, що лінія «не є науковим висновком». Ми
   додаємо саме цей крок.
2. **Еталоном процесу є стаття NASA зі списку ресурсів.** Вона ж показує слабкість звичайної
   регресії: стійкий метод зменшив нахил для Міссісіпі у вісім разів. У прототипі стійкий
   метод уже є.
3. **Названі в челенджі місії досяжні програмно** через Giovanni Time Series API (867
   змінних). Ряд для точки приходить за секунди, є усереднення за прямокутником. Потрібен
   токен Earthdata і бекенд; є місячна квота. Старий сервіс Data Rods закрито.
4. **Станції NOAA є найдешевшим сильним доповненням**: без ключа, працює з браузера, Київ має
   ряд з 1881 року.
5. **Усі п'ять канадських ресурсів для трендів непридатні**: короткі ряди або сирі знімки.

## Що робити першим

1. Зареєструвати обліковий запис Earthdata і отримати токен (`06`, пункт 1). Без нього
   недоступні Giovanni API, інтерфейс Giovanni і AppEEARS.
2. Зібрати ядро на NASA POWER: чат → LLM → вердикт → глобус (`05`, вектор 1).
3. Додати дешеві вектори 3–6 з `05`.

## Як це досліджено

- Сторінки челенджу й ресурсів зчитано напряму; сайти з JavaScript відрендерено в браузері без
  інтерфейсу.
- Живі запити зроблено до NASA POWER, NOAA NCEI, каталогу AppEEARS, списку змінних Giovanni.
- Статтю NASA (PDF, 27 сторінок) прочитано повністю.
- Чотири пошукові субагенти на Haiku поглибили кожне джерело за офіційною документацією.
- Gemini 3.8 Flash зробив огляд статистичних методів. Gemini 4 Argon готував технічну довідку
  по двох API: частину про Giovanni віддав повністю, на AppEEARS вичерпав ліміт у 25 хвилин.
  Його ключові твердження я звірив з офіційними ноутбуками NASA і каталогом метаданих.
  Моделі «Flash 4.0» у списку доступних не було, тому взято 3.8 Flash.
- Кожен факт у файлах джерел позначено: перевірив сам, прочитав субагент або відомо лише з
  уривка пошукової видачі.

Чого не зроблено: нічого, що потребує входу в обліковий запис, і нічого на сайтах із
перевіркою «чи ви людина». Перелік у `06`.
