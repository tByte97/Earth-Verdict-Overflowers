## 1. Що будуємо

**Earth Verdict.** Людина пише твердження про планету («Літа в Києві стали спекотнішими»).
Застосунок показує, що саме перевіряється (змінна, місце, сезон, роки), бере реальний ряд
NASA, рахує тренд і значущість, звіряє з метеостанцією NOAA і виносить один із трьох
вердиктів: **Confirmed / Not proven / Refuted**. Глобус зліва летить у місце, справа панель
з чатом, карткою справи й вердиктом.

### Що має бути на демо (MVP)

1. Питання в чаті → заповнені плашки → вердикт із графіком → глобус у місці.
2. Те саме без чату: плашки заповнюються вручну.
3. Станція NOAA поруч із рядом NASA і бейдж «джерела згодні / розходяться».
4. Тест стійкості до періоду: «значущий у k з n варіантів періоду».
5. Три показові справи, які працюють без інтернету.

Усе інше (Giovanni, карта трендів, пара протилежних регіонів, блок протоколу) — наступний
рівень, у порядку пріоритетів нижче.

### Пріоритети

- **P0** — без цього демо немає.
- **P1** — сильно додає до оцінки, робити після P0.
- **P2** — якщо лишився час.

## 3. Спільні контракти

Їх фіксує Максим у першу годину (M1). Після цього змінювати лише через PR із попередженням
решти.

### `CaseSpec`: що перевіряємо

```json
{
  "claim_text": "Summers in Kyiv are getting hotter",
  "variable_id": "air_temp",
  "place": {"place_id": "om:703448", "name": "Kyiv, Ukraine", "lat": 50.45, "lon": 30.52},
  "season": "JJA",
  "start_year": 1981,
  "end_year": 2025,
  "claim_direction": "increase"
}
```

`season`: `year`, `DJF`, `MAM`, `JJA`, `SON` або число 1–12 (місяць).
`claim_direction`: `increase`, `decrease`, `change`.

### `CheckResult`: що отримуємо

Числа нижче є **заглушкою для фронтенду**, а не реальним результатом.

```json
{
  "case": { "...": "CaseSpec" },
  "variable": {"id": "air_temp", "label": "Air temperature", "units": "°C",
               "definition": "How warm the air is about 2 m above the ground.",
               "caveat": "Reanalysis: a weather model steered by observations, not a thermometer."},
  "series": [{"year": 1981, "value": 19.1}, {"year": 1982, "value": 18.7}],
  "sen":  {"slope_per_year": 0.051, "slope_per_decade": 0.51, "ci_low": 0.032, "ci_high": 0.070, "intercept": 18.9},
  "mk":   {"p": 0.0004, "tau": 0.36, "z": 3.5, "correction": "hamed_rao"},
  "ols":  {"slope_per_year": 0.049, "p": 0.001, "r2": 0.29, "n_eff": 31.2},
  "robustness": [
    {"start_year": 1981, "end_year": 2025, "p": 0.0004, "slope_per_decade": 0.51, "significant": true},
    {"start_year": 1984, "end_year": 2025, "p": 0.001,  "slope_per_decade": 0.55, "significant": true}
  ],
  "robustness_summary": {"significant": 5, "total": 5},
  "witness": {
    "station": {"id": "UPM00033345", "name": "KYIV", "lat": 50.40, "lon": 30.57, "distance_km": 6},
    "series": [{"year": 1981, "value": 19.5}],
    "sen": {"slope_per_decade": 0.47, "ci_low": 0.25, "ci_high": 0.68},
    "mk": {"p": 0.002},
    "agreement": "agree"
  },
  "verdict": "confirmed",
  "reason": "significant_trend",
  "years_to_wait": null,
  "provenance": [
    {"what": "Air temperature", "source": "NASA POWER (MERRA-2)", "product": "T2M",
     "url": "https://power.larc.nasa.gov/api/temporal/monthly/point?...",
     "retrieved_at": "2026-11-14T15:02:11Z", "license": "Public domain (NASA)"}
  ]
}
```

- `verdict`: `confirmed`, `refuted`, `not_proven`.
- `reason`: `significant_trend`, `opposite_trend`, `not_significant`, `short_series`,
  `sources_disagree`, `not_robust`.
- `witness.agreement`: `agree`, `one_source`, `disagree`, `no_station`. Якщо станції немає,
  `witness` = `null`.

### Помилки

```json
{"error": {"code": "source_unavailable", "message": "NOAA did not respond"}}
```

Коди: `unknown_variable`, `place_not_found`, `short_series`, `source_unavailable`,
`llm_unavailable`, `bad_request`.

### Події SSE з `/api/chat`

```
event: text         data: {"delta": "Let me find Kyiv..."}
event: case         data: <CaseSpec>
event: result       data: <CheckResult>
event: explanation  data: {"text": "Summers in Kyiv have warmed ..."}
event: error        data: {"code": "...", "message": "..."}
event: done         data: {}
```
