# Precomputed CMIP6 Scenario Files (`data/cmip6/`)

This directory holds precomputed NASA NEX-GDDP-CMIP6 scenario summaries produced by:

- `tools/fetch_cmip6.py` -> point files `<city>.json` (e.g., `kyiv.json`)
- `tools/fetch_cmip6_region.py` -> regional grid files `region-<name>.json`

> **Note on `region-smoke.json`:** `data/cmip6/region-smoke.json` is a smoke-test artifact generated by `tools/fetch_cmip6_region.py --smoke` (1 model `ACCESS-CM2`, 5×5 bbox `50 30 51 31`, historical `2012-2014` + `ssp585` `2049-2051`). It is not a full multi-model ensemble.

## Regional JSON Layout (`region-<name>.json`)

Compact JSON (no whitespace), coordinates on the common NEX-GDDP-CMIP6 0.25° grid:

```json
{
  "name": "europe-east",
  "bbox": [44.0, 20.0, 53.0, 41.0],
  "grid": {
    "lat": [44.125, 44.375, "..."],
    "lon": [20.125, 20.375, "..."]
  },
  "models": ["ACCESS-CM2", "GFDL-ESM4", "IPSL-CM6A-LR", "MIROC6", "MPI-ESM1-2-HR"],
  "baseline_period": "1995-2014",
  "retrieved": "YYYY-MM-DD",
  "source": "NASA NEX-GDDP-CMIP6 via NCCS THREDDS NCSS (bbox)",
  "catalog_url": "https://ds.nccs.nasa.gov/thredds/catalog/AMES/NEX/GDDP-CMIP6/catalog.html",
  "units": {"tas": "°C", "pr": "mm"},
  "horizons": {
    "years": [2030, 2050, 2070, 2100],
    "windows": {
      "2030": "2021-2040",
      "2050": "2041-2060",
      "2070": "2061-2080",
      "2100": "2091-2100"
    }
  },
  "baseline": {
    "tas": {
      "JJA": "[[lat][lon]]",
      "DJF": "[[lat][lon]]",
      "year": "[[lat][lon]]"
    },
    "pr": {
      "JJA": "[[lat][lon]]",
      "DJF": "[[lat][lon]]",
      "year": "[[lat][lon]]"
    }
  },
  "variables": {
    "tas": {
      "JJA": {
        "ssp126": {
          "median": "[[[horizon][lat][lon]]]",
          "low": "[[[horizon][lat][lon]]]",
          "high": "[[[horizon][lat][lon]]]"
        },
        "ssp245": {},
        "ssp585": {}
      },
      "DJF": {},
      "year": {}
    },
    "pr": {}
  }
}
```

### Array Indexing & Units

- `bbox`: `[south, west, north, east]` in degrees.
- `grid.lat`: ascending list of `nlat` cell latitudes (degrees_north).
- `grid.lon`: ascending list of `nlon` cell longitudes normalized to `(-180, 180]` (degrees_east).
- `baseline[var][season][lat_idx][lon_idx]`: 2D array (`nlat × nlon`) of the ensemble-median 1995–2014 historical seasonal baseline (`tas` in °C rounded to 2 decimals; `pr` in mm rounded to 1 decimal).
- `variables[var][season][scenario][stat][horizon_idx][lat_idx][lon_idx]`: 3D array (`4 × nlat × nlon`) where:
  - `horizon_idx` `0..3` corresponds to `horizons.years` (`[2030, 2050, 2070, 2100]`, 20-year centered windows).
  - `stat` is `"median"` (50th percentile), `"low"` (10th percentile), or `"high"` (90th percentile) across the model ensemble.
  - Values are absolute changes relative to each model's own 1995–2014 baseline (`tas` in °C rounded to 2 decimals; `pr` in mm rounded to 1 decimal).
  - Non-finite / ocean-masked cells are serialized as JSON `null`.
